## Call for Submissions

The golang.design Research aims to provide a place to publish research regarding the programming language Go. Research does not limit to theoretical but also includes practices and case studies.

Please open a pull request with your markdown draft at [golang-design/research](https://github.com/golang-design/research) if you are interested. See our historical posts as an example: https://golang.design/research/posts/.
